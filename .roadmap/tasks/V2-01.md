# V2-01: Computer Vision Board Capture Input Adapter (OpenCV + OCR)

## Overview
Add a pure input-adapter pipeline (`POST /api/import/image/{slug}`) that accepts an uploaded screenshot/photo of a puzzle board, extracts the grid geometry and cell values via OpenCV + OCR/color clustering, and returns a normalized JSON `state` matching the target solver's preset schema so it loads directly into **EDIT MODE** in the web stage.

## Architecture & Scope
* **Backend boundary:** Keep `solvers/*.py` completely free of OpenCV/OCR imports. Implement CV logic in a dedicated module `app/cv_adapter.py` (or `app/importers/`).
* **Supported targets (Phase 1):** `"grid"`-renderer solvers:
  * **Numeric grids:** `sudoku` (1–9 digits), `urjo` (0–8 Moore clues + R/B cells), `palisade` (0–3 clues).
  * **Binary/color grids:** `flip`, `flood`, `unruly`, `packing_grids` (board cells), `maze_navigator` (start/goal/wall/weight color classification).
* **Out of scope (Phase 1):** Custom-canvas/graph puzzles (`liquid_tubes`, `loop_games`) and text/cipher tools (`cipher_suite`, `morse_decoder`) — return a clean `400` / structured capability message for unsupported slugs.

## Implementation Plan

### 1. Dependencies & Graceful Fallback
* Add optional dependency group `[project.optional-dependencies] cv = ["opencv-python-headless>=4.10.0", "pytesseract>=0.3.13", "pillow>=10.0.0"]` in `pyproject.toml` (or `easyocr` / lightweight ONNX digit model if zero-system-binary portability is preferred).
* Guard imports in `app/cv_adapter.py` so `app/main.py` and existing `pytest` suites still boot and pass cleanly even if the `cv` extra is not installed (returning HTTP `501` with installation instructions).

### 2. CV Pipeline (`app/cv_adapter.py`)
1. **Preprocess & Board Localization:**
   * Decode uploaded bytes (`numpy.frombuffer` + `cv2.imdecode`), resize to bounded max dimension, grayscale + adaptive threshold / Canny edges.
   * Detect largest quadrilateral contour (4-point `approxPolyDP`) and apply `cv2.getPerspectiveTransform` + `cv2.warpPerspective` to rectify skewed photos; fall back to full-image bounding box for clean screenshots.
2. **Grid Slicing:**
   * Infer dimensions `(rows, cols)` via horizontal/vertical Sobel/morphological projection profiles (or accept optional user-supplied `rows`/`cols` query/form override, validated against `grid_meta.min_dim` / `max_dim`).
   * Slice warped board into `rows × cols` cell ROIs with inner margin crop (10–15%) to strip gridlines.
3. **Cell Classification (dispatched by solver `grid_meta.mode`):**
   * `number` / `clues`: Check variance/ink ratio for blank cells (`0` / `None`); run single-character OCR (`--psm 10 -c tessedit_char_whitelist=...`) or template/CNN digit matching.
   * `binary` / `cycle` / `palette`: Compute median HSV/RGB color per cell and cluster/match against `grid_meta.colors` (or dominant dark vs. light vs. color centroids).
4. **Schema Normalization & Confidence Payload:**
   * Return `{ "ok": true, "slug": slug, "state": { "board": ... }, "confidence": [[...]], "warnings": [...] }` matching the exact shape of `META["presets"]`.

### 3. FastAPI Endpoint (`app/main.py`)
* Add `POST /api/import/image/{slug}` accepting `multipart/form-data` (`file: UploadFile`, optional `rows: int | None`, `cols: int | None`).
* Look up solver in `discover_solvers()`, validate slug support, invoke `app/cv_adapter.py`, and return normalized state JSON.

### 4. Frontend Upload Hook (`web/index.html`, `web/app.js`)
* Add an **Import Image** button (or drag-and-drop / paste handler on `#stage`) visible when the active solver uses `"renderer": "grid"`.
* On response, populate current editable state, switch to `EDIT` mode so the user can visually verify/fix any misread cells before clicking **Solve**, and highlight low-confidence cells in the log/status bar.

## Verification & Acceptance Criteria
* [ ] Synthetic fixture tests in `tests/test_cv_adapter.py` generate clean & slightly rotated PNG boards (e.g., 4x4/9x9 Sudoku, 6x6 Urjo, 5x5 Flip) via Pillow/NumPy and verify round-trip accuracy through `POST /api/import/image/{slug}`.
* [ ] Unsupported slugs return HTTP `400` with a clear message; missing optional CV dependencies return HTTP `501` without breaking `test_api.py` or `test_solvers.py`.
* [ ] `uv run pytest` passes with exit code `0`.
