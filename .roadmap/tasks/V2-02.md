# V2-02: Polyomino / Pentomino DLX Exact Cover Solver

## Overview
Add a pure-Python **Algorithm X / Dancing Links (DLX)** solver in `solvers/polyomino_dlx.py` adhering to the single-file solver contract (`META` + `solve()`). It supports classic Pentomino tiling, Tetromino/custom polyomino sets, arbitrary rectangular or holed boards, and step-by-step visualization of exact-cover selection and backtracking.

## Architecture & Scope
* **Solver module:** `solvers/polyomino_dlx.py` (separate from `solvers/packing_grids.py`, which handles Nonograms/Picross).
* **Renderer:** Use `"renderer": "grid"` with `"mode": "palette"` (or `"token"`) and per-piece color mapping in `grid_meta.colors` so every placed polyomino renders with a distinct color and piece letter (`F, I, L, P, N, T, U, V, W, X, Y, Z`, etc.), while `-1` / `#` cells represent blocked holes on the board.
* **Pure Python:** No external dependencies required; standard library only.

## Implementation Plan

### 1. Polyomino Symmetry & Placement Generator
* Define canonical pentomino (12 pieces) and tetromino (5 pieces) shapes plus support for custom `pieces` dicts in `state` (`{ "A": [[0,0],[0,1],[1,0]], ... }`).
* Implement `_orientations(cells, allow_flip: bool)` to generate unique normalized rotations (and reflections when `allow_flip=True`) translated to `(0, 0)`.
* For a board of size `rows × cols` with optional blocked cells (`board[r][c] == -1`), enumerate all valid placements `(piece_id, [(r, c), ...])` that stay in-bounds and avoid blocked cells.

### 2. Dancing Links (DLX) Engine
* Build sparse circular doubly-linked matrix columns:
  * **Primary columns:** 1 column per piece ID (each piece used once, or optional multi-use/subset mode) + 1 column per unblocked `(r, c)` board cell.
* Implement `cover(col)`, `uncover(col)`, and MRV (Minimum Remaining Values — smallest `col.size`) column selection heuristic for fast pruning.
* Maintain cooperative cancellation via `should_abort()` inside the recursive search loop.

### 3. Solver Contract (`META` & `solve`)
* **`META`:**
  * `slug`: `"polyomino_dlx"`, `name`: `"Polyomino Tiling (DLX)"`, `category`: `"Packing"`
  * `renderer`: `"grid"`, `grid_meta` with palette colors for pieces `1..12` + blocked cell `-1`.
  * `params`:
    * `allow_flip` (`bool`, default `True`) — allow piece reflections.
    * `step_stride` (`select`, e.g. `"Every Step"` / `"Key Branches"`) — throttle `explore`/`backtrack` yields on larger boards (like 6×10 Pentominoes) so SSE streaming stays responsive.
* **`presets` (all mathematically solvable & fast):**
  1. `"4x5 Pentominoes"` (4-piece subset or custom quick-solve preset)
  2. `"6x10 Classic Pentominoes"` (all 12 pentominoes)
  3. `"8x8 Checkerboard Hole"` (all 12 pentominoes with 2×2 center hole blocked)
  4. `"4x4 Tetromino Subset"` (lightweight preset for instant test execution)
* **`solve()` step stream:**
  * Yield `"start"` with initial empty/holed board.
  * Yield `"explore"` when placing a piece, `"backtrack"` when uncovering/removing a piece, highlighting the affected cells.
  * Yield `"solution"` with completed piece-ID board and stats (`placements`, `backtracks`, `nodes_visited`), or `"failed"` with diagnostic message (e.g., cell-count vs. total piece-area mismatch).
